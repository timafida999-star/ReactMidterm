CODEX EXILIS — готовый React SPA / Vite

1. Установите Node.js 22.12+ или Node.js 24 LTS.
2. Распакуйте архив и откройте терминал в папке codex-exilis.
3. Выполните:

   npm ci
   npm run dev

4. Откройте адрес, который Vite покажет в терминале.

Проверка:
   npm test

Production-сборка:
   npm run build
   npm run preview

В папке dist уже есть готовая production-сборка для статического хостинга.
Не открывайте index.html двойным кликом: приложению нужен HTTP-сервер.

Внутри проекта:
- src/data/records.json: 120 исходных записей.
- src: React-компоненты, hooks, API, SCSS и тесты.
- README.md: запуск, архитектура, ограничения localStorage и deployment.
- docs/DEFENSE_RU.md: русское руководство для защиты.
- docs/QA.md: выполненные проверки.

Новые записи и избранное хранятся в текущем браузере.
Внешний backend и API-ключи не нужны.

Проект подготовлен как файлы по вашему запросу.
GitHub-репозиторий и публичный deployment пока не созданы.
Для сдачи по требованиям курса их необходимо добавить отдельно.
